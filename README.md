# Sukoon — Support

Welcome! This is the support page for **Sukoon**, an iOS app that helps you replace noise with tranquility — one day at a time.

## Need help?

If you have a question, found a bug, or want to request a feature, please reach out:

**📧 Email:** sukoon.mgmt@gmail.com
**⏱️ Response time:** usually within 24 hours

## Common questions

**Q: Why isn't my streak updating?**  
A: Make sure you've pledged today. Your streak counts the days since you last listened to music. If you slipped, tap "I listened to music" on the home screen to reset honestly — that's how the app is designed to work.

**Q: The Shortcut reminder isn't firing when I open Spotify.**  
A: Check that you've set up the automation correctly in the Shortcuts app. Open Shortcuts → Automation → find the Sukoon Reminder → make sure "Run Immediately" is on (not "Ask Before Running"). If it's still not working, email me and I'll help debug.

**Q: Will my data be lost if I delete the app?**  
A: Yes. Sukoon stores everything locally on your device. Reinstalling starts fresh. This is intentional — no accounts, no cloud, no tracking.

**Q: I forgot my data after switching phones.**  
A: Sukoon doesn't sync between devices. Each install is independent. If this is important to you, let me know — it's something I'm considering for a future update.

**Q: How do I cancel my subscription?**  
A: Open the iOS Settings app → tap your name → Subscriptions → Sukoon → Cancel. This is handled entirely by Apple.
